# AI-Based Interactive Robotic Emotion System

## 🚀 Overview
This project is an AI-powered interactive system that detects human emotions in real time and responds using voice interaction and emotion-based music playback.

It integrates computer vision, machine learning, and human-computer interaction into a single pipeline.

## 🧠 Features
- Real-time face detection (MediaPipe)
- Emotion recognition (DeepFace / ONNX model)
- Voice interaction (SpeechRecognition + pyttsx3)
- Gemini AI-based conversational responses
- Emotion-based music recommendation system
- Continuous perception-to-action pipeline

## 🔄 System Pipeline
Camera Input → Face Detection → Emotion Recognition →  
→ Decision Logic → Voice Response + Music Playback

## 🛠️ Tech Stack
- Python
- OpenCV
- MediaPipe
- DeepFace / HSEmotion
- Google Gemini API
- SpeechRecognition & pyttsx3
- Pygame (audio)
